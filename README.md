# 층간소음 기록기 (웹앱 / PWA)

휴대폰 브라우저에서 바로 쓰는 층간소음 기록 앱입니다. 설치할 필요 없이 HTTPS 주소로 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 기능
- **마이크 원본 측정**: 에코 제거·노이즈 억제·자동 이득을 끄고 받아서 저주파(쿵쿵)가 깎이지 않게 함
- **dB(A) 측정**: FFT 기반 A가중, 1분 등가소음도(Leq), 최고소음도(Lmax), 20–200Hz 저주파 레벨
- **법정 기준 비교**: 주간 Leq 39 / Lmax 57, 야간 Leq 34 / Lmax 52 dB(A) 초과 여부 표시
- **저주파 증폭 녹음**: 로우쉘프 + 60Hz 피크 부스트, 500Hz 이상 차단(선택), 컴프레서·리미터
- **원본 + 증폭 파일 동시 녹음**, 각 파일 SHA-256 해시 기록
- **바닥 진동**: 휴대폰 가속도 센서로 충격 피크(mg) 기록
- **사건 자동 감지/메모**, CSV 로그, 요약 보고서(txt) 내보내기
- 측정 중 화면 꺼짐 방지

## 실행 / 배포
마이크는 HTTPS(또는 localhost)에서만 동작합니다.
- GitHub Pages: 저장소 Settings → Pages에서 이 브랜치를 선택하면 `https://<계정>.github.io/<저장소>/floor-noise-app/` 로 접속
- 로컬 테스트: `cd floor-noise-app && python3 -m http.server 8000` 후 `http://localhost:8000`

## 중요한 한계
- 증폭은 **듣기용**입니다. dB 수치는 증폭 전 원본 신호로만 계산합니다. 증폭된 값을 측정값으로 쓰면 조작으로 보일 수 있습니다.
- 휴대폰 마이크는 공인 소음계가 아닙니다. 보정 전 수치는 참고값이며, 법적 판단에는 이웃사이센터·공인기관 측정이 필요합니다. 이 앱은 그 전에 반복적인 피해를 기록해 두는 정황 자료용입니다.
- 일부 휴대폰(특히 iPhone)은 브라우저가 요청해도 마이크 하드웨어 자체가 약 50–100Hz 이하를 걸러냅니다.
